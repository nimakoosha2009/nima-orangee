# Nima ORANGE VPN — نسخه بازسازی‌شده اندروید

این پروژه از نو به Flutter بازسازی شده و برای تونل واقعی از پکیج `sing_box` استفاده می‌کند؛ این پکیج هسته libbox/sing-box را داخل Android VpnService اجرا می‌کند. برخلاف نسخه HTML اولیه، دکمه اتصال صرفاً وضعیت نمایشی را تغییر نمی‌دهد.

## منبع سرورها
- هیچ سرور، آدرس، اکانت یا کانفیگ پیش‌فرضی داخل برنامه قرار ندارد.
- فهرست کانفیگ‌ها در نصب اولیه کاملاً خالی است.
- اتصال فقط با کانفیگ خارجی‌ای انجام می‌شود که کاربر از طریق کلیپ‌بورد، ورود دستی یا QR وارد کند.
- لینک‌های اشتراک HTTP/HTTPS در این نسخه به‌عنوان کانفیگ مستقیم پذیرفته نمی‌شوند؛ باید لینک اختصاصی پروتکل (مانند `vless://`) وارد شود.

## امکانات فعلی
- رابط فارسی RTL با تم نارنجی/مشکی
- اتصال/قطع اتصال از طریق هسته واقعی sing-box
- درخواست مجوز VPN اندروید و مجوز اعلان
- ورود چند کانفیگ از کلیپ‌بورد یا متن
- اسکن QR با دوربین
- ذخیره محلی رمزگذاری‌شده فهرست کانفیگ‌ها (Android Keystore-backed secure storage)
- نمایش سرعت دانلود/آپلود دریافتی از موتور VPN
- جلوگیری از افزودن تکراری کانفیگ‌ها
- نمایش خطای واقعی موتور هنگام شکست اتصال

## پروتکل‌ها
موتور sing-box لینک‌های VLESS (از جمله Reality)، VMess، Trojan، Shadowsocks، Hysteria/Hysteria2، TUIC، AnyTLS، WireGuard و HTTP/SOCKS را پشتیبانی می‌کند. پشتیبانی از جزئیات هر transport تابع قابلیت‌های نسخه هسته است؛ XHTTP، mKCP و ShadowsocksR در بیلد پیش‌فرض پشتیبانی نمی‌شوند.

## پیش‌نیاز ساخت APK
- Flutter SDK پایدار (نسخه سازگار با Dart 3.3+)
- Android SDK و Android SDK Platform
- JDK 17
- اتصال اینترنت در اولین build برای دریافت وابستگی‌ها و باینری libbox

## آماده‌سازی پروژه
در ترمینال، وارد پوشه پروژه شوید و اجرا کنید:

```bash
flutter create --platforms=android .
flutter pub get
flutter run
```

برای APK:
```bash
flutter build apk --release --target-platform android-arm64
```

برای خروجی‌های ABI جدا:
```bash
flutter build apk --release --split-per-abi
```

خروجی در `build/app/outputs/flutter-apk/` قرار می‌گیرد.

## نکات مهم
1. فایل `android/app/src/main/AndroidManifest.xml` این بسته، مانیفست پایه است. پس از `flutter create` بررسی کنید نام اپ و مجوز CAMERA حفظ شده باشد. پلاگین sing_box سرویس VPN و مجوزهای موردنیاز خود را از طریق manifest merge اضافه می‌کند.
2. هسته libbox حجیم است و اولین ساخت ممکن است زمان‌بر باشد. برای حجم کمتر، APK را فقط برای ABI گوشی هدف بسازید.
3. برای انتشار اپی که sing-box را در خود توزیع می‌کند، شرایط GPL-3.0-or-later و اعلان‌های مجوز آن باید رعایت شوند. این بسته کد متناظر اپ را همراه دارد؛ پیش از انتشار عمومی مجوزها و نام‌گذاری تجاری را بررسی کنید.
4. هیچ سرور داخلی، کانفیگ آزمایشی یا سرور ساختگی در برنامه وجود ندارد. برای اتصال فقط باید کانفیگ خارجی معتبر و فعال خودتان را وارد کنید.
5. ساخت و تست نهایی روی دستگاه واقعی هنوز باید انجام شود. این محیط Android SDK/Flutter ندارد؛ بنابراین APK امضاشده و قابل نصب در این مرحله تولید نشده است.

## امنیت
لینک‌های کانفیگ شامل UUID، رمز یا توکن حساس هستند. آن‌ها را در اسکرین‌شات، گزارش خطا یا مخزن عمومی منتشر نکنید. لینک‌ها در فضای امن محلی اندروید (با پشتیبانی Android Keystore از طریق flutter_secure_storage) ذخیره می‌شوند.
